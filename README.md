# Automobile Sales Analytics Dashboard

## Project Overview

An interactive Automobile Sales Analytics Dashboard created using Tableau to analyze automobile sales performance.

## Tools Used

- Tableau
- Excel / CSV
- Data Analysis
- Data Visualization

## Key Analysis

- Total Sales
- Total Profit
- Total Tax
- Year-wise Sales
- Product-wise Sales
- Country-wise Sales
- Country-wise Profit
- Interactive Filters
- Dashboard Actions

## Dataset

Automobile sales data covering 2022–2026.

## Dashboard

Created an interactive Tableau dashboard to generate business insights from automobile sales data.

Tableau | Data Analysis | Data Visualization | Dashboard Development
